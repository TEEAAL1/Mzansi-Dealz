---
name: Honest storefront merchandising
description: Rules for presenting popularity, reviews, and customer trust content when the storefront lacks a review or analytics integration.
---

Use catalogue/order-derived signals for best-selling merchandising. Do not invent ratings, testimonials, customer names, or review counts. When review records are unavailable, use a clearly labeled feedback invitation and keep payment, delivery, and returns claims aligned with the configured checkout and policy pages.

**Why:** Trust-focused ecommerce copy must remain verifiable; fabricated social proof undermines the store’s stated goal of becoming more trustworthy.

**How to apply:** Before adding testimonials, star ratings, or “most loved” claims, check for a real review/analytics data source. If none exists, use the existing feedback contact path and describe popularity only from actual order data.

Top-seller merchandising should resolve from valid order history by default, while any curated override must still use active, in-stock catalogue products and clearly label itself as hand-picked.

**Why:** A homepage popularity claim is customer-facing evidence; it should never be driven by fixture products, unavailable inventory, or an unverified static image.

**How to apply:** Exclude cancelled, failed, refunded, test, inactive, and out-of-stock products from automatic rankings and curated selection; show the active mode and freshness timestamp beside the carousel.
